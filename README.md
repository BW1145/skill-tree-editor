# 通用技能树编辑器

在浏览器中编写技能树，设置技能等级、学习花费、前置关系和变量效果，导出 JSON 接入自己的项目。

## 使用

下载整个仓库或解压 ZIP，双击 `index.html` 打开。编辑器在本地运行，无需安装依赖或连接 API。

1. 添加分类和技能，填写每级效果及花费。
2. 在「变量设置」中添加项目属性或状态。
3. 为技能选择影响变量、数值来源和生效条件。
4. 使用「试算效果」查看组合结果。
5. 点击「保存项目」下载可继续编辑的 JSON，或「导出技能数据」供程序读取。

自动草稿保存在当前浏览器，换电脑或移动文件夹前请保存项目文件。

## 功能

- 分类管理：新增、改名、配色、排序与技能转移。
- 技能编辑：多级效果、每级费用、主动／被动／开关类型。
- 技能关系：前置等级、连线、拖动布局和自动排列。
- 自定义变量：数值、文字和是／否，支持固定上下限及关联上限。
- 数值效果：增加、减少、乘以、设值，以及「引用变量 × 倍率 ＋ 加值」。
- 条件组合：每项效果可设置多个条件，选择全部或任一满足。
- 效果试算：组合技能等级、输入变量与开关，查看结果。
- 本地保存、导入导出、撤销重做和文字预览。

当前数据格式为版本 3，支持导入版本 1 和版本 2 项目。效果引用和条件读取本次计算前的输入值，关联上限使用计算后的上限。

## 开发检查

安装 Node.js 后，在项目目录执行：

```sh
node effects.test.cjs
```

检查覆盖关联上限、动态数值、多条件、旧版导入、导出重载及事件去重。
